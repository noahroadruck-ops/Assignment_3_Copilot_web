I asked Copilot to create a basic outline for creating a social media website along with prompts for the basic design. I broke down the problem with prompts for each part of the website.

My approach changed as I started to first make each part of the website first, then go back later to revise it. This helped me get the big picture down first, so I could keep everything consistent.

One part wit hthe development process with Github copilot that surprised me is how intergrated it is with VS code. I liked how it is able to create everything in the chat box in VS code, and how it can implement directly into the files. 

4. What did you learn about the technology you used that you didn't know before?

I learned that utilizing AI can be great for creating basic code so it can cut down the project time without wasting time with redundant code.
